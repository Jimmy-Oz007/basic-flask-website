# Basic Flask Website V2

A responsive multi-page website built using Flask, Python, HTML, CSS, JavaScript, and SQLite.

This project was created as part of my personal software development portfolio and focuses on learning full-stack web development fundamentals.

## Features

* Multi-page website
* Responsive layout
* Navigation bar
* Dark mode toggle
* Contact form
* SQLite database integration
* Admin page for viewing submitted messages
* Mobile-friendly design

## Technologies Used

* Python
* Flask
* HTML5
* CSS3
* JavaScript
* SQLite

## Pages

### Home

Introduces the website and highlights the main technologies used.

### About

Provides information about the developer and project goals.

### Projects

Displays current and future software projects.

### Contact

Allows users to submit messages through a contact form.

### Admin

Displays submitted contact messages stored in the SQLite database.

## Installation

Install Flask:

```bash
py -m pip install flask
```

Run the application:

```bash
py app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```
